# Lite IPTV

A simple M3U / UDP IPTV player for LG webOS TVs (Homebrew).

## Install
Install through Homebrew Channel, or sideload `com.homebrew.liteiptv_1.0.0_all.ipk`.

## Repo layout
- App source: `appinfo.json`, `index.html`, `js/`, `css/`, `server/`, icons
- `release-assets/`: upload these two files to a GitHub Release (not needed in git)
- `apps-repo-submission/liteiptv.yml`: file to submit to webosbrew/apps-repo

Replace `Zyanoo` in `release-assets/*.json` and `apps-repo-submission/*.yml` with your GitHub username before releasing.
